## Test runners & commands

- Runner: pytest. `[tool.pytest.ini_options]` pins `testpaths = ["tests"]`
  and defines markers `core` and `real_env` (pyproject.toml:156-169).
- Standard commands (README.md:333-334, CONTRIBUTING.md:44-45):
  - `pytest -m core -q` — fast smoke subset, one test per core function
    (includes the cairn-on-cairn self-demo; observed at baseline:
    26 passed, 2105 deselected).
  - `pytest -q` — full suite, the CI path (observed scale: tests/ has 151
    entries; CONTRIBUTING says ~60 test files).
- Golden parser tests: `pytest tests/test_golden_parsers.py` — parametrized
  over tests/fixtures/golden/<lang>/{sample,expected.json}; regenerate via
  tests/fixtures/golden/regenerate.py.
- CI test matrix: Python 3.10-3.14 on ubuntu-latest (ci.yml:155), runs
  `pytest -m core -q` then the full suite with coverage.

## Conventions

- Commits/PR titles: conventional — `type(optional-scope): subject` with
  types feat fix chore docs ci refactor perf test build style revert
  (ci.yml pr-title gate; commitizen derives the SemVer bump).
- Layered review pipeline: Layer 0 pre-commit (ruff F-only, gitleaks,
  check-yaml/toml/merge-conflict/large-files, debug-statements —
  .pre-commit-config.yaml); Layer 1 CI (tests, pip-audit hard gate,
  bandit advisory -s B608, mypy advisory ~52 known errors, PR-title,
  dependency-review); Layers 2-3 human/agent review
  (docs/review-checklist.md, PR template audit checklist).
- Shipping procedure: docs/contribution-workflow.md — branch →
  `pre-commit run --all-files` → conventional commit → push feature
  branch → PR with audit checklist → watch CI → fix on same branch →
  post-merge `cairn update` + `record_memory`. Never push directly to
  main; never `--no-verify` past a pre-commit failure.
- Changelog: Keep a Changelog 1.1.0 (CHANGELOG.md:7); entries under
  `## [Unreleased]` with `### Added` / `### Fixed` / `### Changed`;
  version sections `## [X.Y.Z] - YYYY-MM-DD`.
- Ruff gate is pyflakes-only (`select = ["F"]`, pyproject.toml:192-193);
  tests/fixtures and vendored benchmark corpora are excluded
  (pyproject.toml:186-190).
- Post-task hygiene (AGENTS.md): `cairn update` after changes;
  `cairn doctor` for perf/fallback paths; `record_memory` for learnings.
