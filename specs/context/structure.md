## Per-area ownership

- Ownership guidance is codified in `docs/audit-checklist.md:31` — the
  parser-correctness area explicitly covers `scip_importer.py`, `kotlin.py`,
  `typescript.py`, `php.py`, `routes.py` with per-area audit entries, to be
  re-run "after adding a parser" (docs/audit-checklist.md:195).
- `src/cairn/parsers/_registry.py` is the single seam where language wheels
  are bound (mapping at `_load_language_module`, special loaders at
  `_SPECIAL_LOADERS`, plugin group `cairn.parsers.v1`).
- Any agent editing files must follow the workspace AGENTS.md workflow:
  `ask_compass(file_path)` before editing, `cairn update` +
  `record_memory` after; PRs gated by `.github/PULL_REQUEST_TEMPLATE.md`
  checklist and `docs/review-checklist.md`.
- Status words/checkboxes live only in the orchestrator's task.md (spec
  pipeline rule); this file carries none.
