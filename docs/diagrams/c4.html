Cairn · C4 Model

Cairn in three C4 levels

System context, containers, and the MCP server's components. Every arrow shown is deterministic and local — the LLM sits off the query path.

Level 1 · System Context

Who uses cairn, and what it talks to

Agents and developers are the only actors. Cairn reads the workspace and never serves an answer that an LLM produced — synthesis happens off-path and must pass the critic.

Level 2 · Containers

Three surfaces, three engines, one store

Every surface reads and writes the same .kg SQLite store under ~/.cairn/<workspace>. The dashboard opens read-only connections; the LLM never sits on any of these query paths.

Level 3 · Components — MCP Server

Inside the 22-tool surface

Tool counts are verified at boot — exactly 22. The four groups are thin dispatch layers; every answer comes from the engines behind them.
